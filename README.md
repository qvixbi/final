# Планировщик задач

Простой планировщик задач на Go. Позволяет добавлять задачи, редактировать их, удалять и отмечать выполненными.

Для хранения задач используется SQLite.

## Запуск

Для запуска нужен Go.

Скачайте зависимости:

```bash
go mod tidy
```

Запустите приложение:

```bash
go run .
```

После запуска откройте в браузере:

http://localhost:7540

База данных `scheduler.db` создаётся автоматически при первом запуске.

## Тесты

Сначала запустите сервер, затем в другом терминале выполните:

```bash
go test ./tests
```

## Повторяющиеся задачи

Поддерживаются два правила:

- `d N` — повторять через N дней.
- `y` — повторять каждый год.
